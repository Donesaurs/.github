Done. is a modular, all-in-one app for managing personal life — calendar, tasks and routines, gym tracking, study planning, notes, weekly reviews, and optional AI assistance, brought into one consistent workspace. Enable only the modules you need.

## Repositories

- [Done](https://github.com/Donesaurs/Done) — the app itself: backend, macOS (Electron), and Android clients
- More repositories (landing page, etc.) coming as the project grows

## Status

**Phase 0 — Definition.** Product scope and architecture are being settled before application scaffolding begins.

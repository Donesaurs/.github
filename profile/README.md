## 🔍 Overview

**Done.** separates a small core — app shell, navigation, settings, module registry, shared design system, notifications, quick capture, and an AI gateway — from independent feature modules that register with it. Disabling a module hides it from navigation and dashboards but keeps its data until you choose to delete it.

Built primarily for daily personal use, and as a deliberate learning project for frontend and backend engineering.

## 🛠️ Tech Stack

Confirmed:

- **Electron** — macOS app shell
- **Elysia (Bun)** — backend framework
- **Prisma** — ORM
- **PostgreSQL** — database
- **Codex CLI** (`codex exec`) — AI, via an existing ChatGPT/Codex subscription rather than pay-per-token billing

Proposed, not yet confirmed:

- **Expo (React Native)** — Android app
- **Tamagui** — shared design system
- A pay-per-token API as a swappable AI fallback
